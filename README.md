# คู่มือสิทธิเมื่อออกจากราชการ

หน้าเว็บไฟล์เดียวที่อธิบายสิทธิของกำลังพลกองทัพบกเมื่อลาออก เกษียณ หรือพ้นจากราชการ
ว่าได้เงินอะไร ต้องทำอะไร ครอบครัวมีสิทธิอะไร และกรณีไหนเสียสิทธิ พร้อมเครื่องคิดเงินในหน้า

> **ไม่ใช่เอกสารทางราชการ** จัดทำโดยกำลังพลเพื่อแบ่งปันความรู้ ยังไม่ผ่านการตรวจของหน่วยงานที่รับผิดชอบ
> ก่อนตัดสินใจเรื่องลาออกหรือเรื่องเงิน ให้แผนกประวัติและบำเหน็จบำนาญของหน่วยยืนยันทุกครั้ง

## เปิดดู

เปิดหน้าเว็บได้ที่ **https://intakaew.github.io/army-leaving-service-handbook/**

หรือดาวน์โหลด `index.html` กับ `bg.jpg` ไว้ในโฟลเดอร์เดียวกัน แล้วเปิด `index.html` ในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร (ต้องต่ออินเทอร์เน็ตเฉพาะเพื่อโหลดฟอนต์ Noto Sans Thai)

| บท | เนื้อหา |

| 1 | ออกจากราชการได้ทางไหน และแต่ละทางได้อะไร |

| 3 | เบี้ยหวัด: ใครมีสิทธิ อัตรา กองหนุนชั้นที่ 1–3 และเมื่อไรถูกงด |

| 7 | ตารางสถานการณ์ที่ได้สิทธิและเสียสิทธิ |
| 8 | เรื่องที่ต้องเคลียร์: หนี้ อทบ. ฌาปนกิจ บ้านพัก รับ–ส่งหน้าที่ |
| 9 | สิ่งที่คู่มือยังตอบไม่ได้ |

## ระดับความแน่นอนของเนื้อหา

ทุกข้อมีเลขมาตราหรือเลขที่หนังสือกำกับ และมีป้ายสามระดับ

- **ก** อ่านจากตัวบทหรือภาพหน้าเอกสารโดยตรง
- **ข** อ่านด้วยโปรแกรมแปลงภาพเป็นข้อความ ยังไม่ได้เทียบทุกตัวอักษร
- **ค** มาจากเอกสารรองหรือยังไม่ได้ตรวจฉบับล่าสุด

## แหล่งที่มาหลัก

- พ.ร.บ.บำเหน็จบำนาญข้าราชการ พ.ศ. 2494 และ พ.ร.บ.กองทุนบำเหน็จบำนาญข้าราชการ พ.ศ. 2539 (ฉบับสำนักงานคณะกรรมการกฤษฎีกา)
- ข้อบังคับกระทรวงกลาโหมว่าด้วยเงินเบี้ยหวัด พ.ศ. 2495 และที่แก้ไขเพิ่มเติม (เผยแพร่โดยกรมการเงินกลาโหม)
- พ.ร.บ.รับราชการทหาร พ.ศ. 2497
- พ.ร.ฎ.เงินสวัสดิการเกี่ยวกับการรักษาพยาบาล พ.ศ. 2553 (ราชกิจจานุเบกษา)
- ระเบียบกองทัพบกและหนังสือแจกจ่ายที่ระบุเลขที่ไว้ท้ายแต่ละหัวข้อในหน้าเว็บ

## ข้อจำกัดที่ควรรู้

- กฎหมายและระเบียบแก้ไขได้ เนื้อหาตรวจกับตัวบทเมื่อ 8 ต.ค. 2569 และยังไม่ได้ไล่ตรวจฉบับแก้ไขล่าสุดครบทุกฉบับ
- เกณฑ์ ช.ค.บ. ขั้นต่ำ 11,000 บาทเป็นของปี 2567 และกำหนดโดยพระราชกฤษฎีกา
- เครื่องคิดเงินเป็นการแทนค่าในสูตร ไม่ใช่ผลการคำนวณของทางราชการ
- ตัวเลขตัวอย่างในหน้าเป็นตัวเลขสมมติทั้งหมด
- รายการที่ยังไม่ยืนยันอยู่ในบทที่ 9 ของหน้าเว็บ
